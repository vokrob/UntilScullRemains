# UntilScullRemains

## Описание

Видеоигра в жанре Roguelike, механикой которой является поэтапная потеря конечностей персонажем-скелетом при получении урона. Каждая потерянная конечность меняет игровые характеристики и доступные стили прохождения.

**Ключевые особенности**

- **Система конечностей:** целый, без рук, без рук и ног, только голова
- **Оружия:** меч, двуручный меч, лук, магический посох, рукопашный бой
- **Враги:** слайм, гриб, летучая мышь
- Генерация комнат с препятствиями и сундуками
- Сохранение после прохождения каждой комнаты

## Стек технологий

- **Движок:** Unity
- **Язык:** C#
- **Среда разработки:** Visual Studio 2022
- **Спрайты:** LibreSprite
- **Система контроля версий:** Git, GitHub
- **Библиотеки:** A\* Pathfinding Project, Unity Input System

## Инструкция по установке

1. Установите Unity.
2. Клонируйте репозиторий:
   ```
   git clone https://github.com/vokrob/UntilScullRemains
   ```
3. Откройте проект в Unity Hub.
4. Соберите проект через **File → Build Settings → Build**.
5. Запустите полученный исполняемый файл.

## Инструкция по использованию

| Действие | Клавиши |
|----------|---------|
| Движение | WASD / Стрелки |
| Атака | Левая кнопка мыши |
| Смена оружия | Цифровые клавиши / Колесо мыши |

**Цель:** пройти комнаты, сражаясь с врагами и собирая предметы. Избегайте потери конечностей - каждая конечность даёт штрафы и бонусы. Когда останется лишь голова, любое попадание приводит к смерти.
