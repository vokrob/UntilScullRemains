# UntilScullRemains

## Описание

Видеоигра в жанре Roguelike, механикой которой является поэтапная потеря конечностей персонажем-скелетом при получении урона. Каждая потерянная конечность меняет игровые характеристики и доступные стили прохождения.

**Ключевые особенности**

- **Система конечностей:** целый, без рук, без рук и ног, только голова
- **Оружия:** меч, двуручный меч, магический посох, удар ногой, атака телом, атака головой
- **Враги:** слайм, гриб, летучая мышь
- **Генерация комнат:** сетка с препятствиями, шипами и сундуками
- **Система маны:** для посоха

## Стек технологий

- **Движок:** Unity
- **Язык:** C#
- **Среда разработки:** Visual Studio
- **Спрайты:** LibreSprite
- **Система контроля версий:** Git, GitHub
- **Библиотеки:** NavMeshPlus, Unity Input System, TextMeshPro, Tilemap Extras

## Инструкция по установке

1. Установите Unity Hub
2. Клонируйте репозиторий
3. Откройте проект в Unity Hub
4. Соберите проект
5. Запустите полученный файл

## Инструкция по использованию

| Действие | Клавиши |
|----------|---------|
| Движение | WASD |
| Атака | Левая кнопка мыши |
| Взаимодействие | E |
| Пауза | Escape |

**Цель:** пройти все сгенерированные комнаты, сражаясь с врагами и открывая сундуки. Каждая конечность заменяет текущее оружие на более слабое. Когда останется лишь голова, любое попадание приводит к смерти.
